## Cenário de decisão

<ExampleBox>A turma define termos técnicos e também cataloga projetos com vários campos e filtros.</ExampleBox>

## Como decidir

- Escolha **Glossário** quando sua característica principal for indispensável ao objetivo.
- Escolha **Base de dados** quando a experiência oferecida pela segunda opção reduzir etapas ou barreiras.
- Combine as opções de **Glossário × Base de dados** somente quando cada uma tiver função distinta e explícita.

<ImportantBox title="Decisão recomendada">Use Glossário para verbetes; escolha Base de dados para registros estruturados com campos heterogêneos.</ImportantBox>
