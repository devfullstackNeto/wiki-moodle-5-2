## Entenda antes de agir

Use logs para eventos, participação para ações em atividades, conclusão para critérios, notas para avaliação e relatórios próprios para tentativas.

<ValidationNotice>Confirme no Moodle institucional os nomes, caminhos, capacidades e opções que afetam **Escolher o relatório adequado** antes de publicar esta orientação.</ValidationNotice>
