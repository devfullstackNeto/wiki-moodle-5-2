# Controle de pendências

| Prioridade | Pendência | Validação necessária |
|---|---|---|
| Alta | Versão corretiva exata | Administração do Moodle ou `version.php` autorizado |
| Alta | Tema, idioma pt_br e navegação | Capturas com contas de teste por papel |
| Alta | Módulos, blocos e plugins habilitados | Administração → Plugins, por equipe autorizada |
| Alta | Fluxos SUAP | Equipes SUAP/AVA e curso de demonstração |
| Alta | Identidade, domínio, contato, políticas e licença | Comunicação e responsáveis institucionais |
| Média | BigBlueButton, LTI, H5P e SCORM | Serviços, bibliotecas, privacidade e relatórios |
| Média | URL canônica e sitemap | Definir `SITE_URL` no build de publicação |
| Média | Capturas e vídeos | Produzir após homologação textual e visual |
| Baixa | Analytics | Selecionar solução compatível com privacidade; não está ativada |
